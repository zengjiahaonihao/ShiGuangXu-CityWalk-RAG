# 武汉 · 昙华林与汉口里分

> 城市：湖北武汉　资料类型：老街史料 / 近代里分与租界街区
> 一句话：昙华林藏着武昌的文脉，汉口的里分藏着近代中国的市井——两江三镇，各有各的老。

## 一、两江三镇：一座被水切开又缝合的城市

- 武汉由**武昌、汉口、汉阳**三镇组成，长江与汉水在此交汇，是中国**地理位置中心**（"**九省通衢**"）。
- 三镇性格不同：**武昌**为政治文教中心（明清湖广总督驻此，今高校云集）；**汉口**为商业与租界中心（近代"**东方芝加哥**"）；**汉阳**为工业发源地（张之洞办**汉阳铁厂**、**汉阳兵工厂**）。
- 武汉**1986 年**列为**国家历史文化名城**。

## 二、昙华林：一条街的三教九流

- **昙华林**位于武昌区花园山北麓，是一条长约 **1200 米**的老街，形成于**明代**（因花园山南麓多种昙花，"**昙华林**"即"昙花之林"），繁盛于**晚清至民国**。
- 街区的独特之处在于**多元文化共处**：**天主教堂、基督教堂、佛寺、道观、教会学校、医院、医院、学堂、花园别墅**挤在同一条街上。
- 代表建筑：
  - **瑞典教区旧址**（1890 年代，瑞典行道会在汉传教的基地）；
  - **崇真堂**（1864 年，基督教中华循道会）；
  - **文华书院 / 华中大学**（1871 年创办，中国最早的教会大学之一，今湖北中医学院与武汉十四中一带；**文华公书林**是中国最早的公共图书馆之一）；
  - **仁济医院**（1866 年，湖北最早的西医医院之一）；
  - **花园山圣家堂**（1889 年）；
  - **钱基博（钱锺书之父）故居**、**石瑛旧居**、**徐源泉公馆**等名人旧居。
- 2000 年代起进行保护性整治，成为武昌的文创与老街地标。

## 三、汉口里分：近代中国的"集体住宅"

- **里分**（武汉又称"**里份**""**里弄**"）是汉口特有的近代**联排住宅**形态，兴起于 **1900 年代至 1930 年代**，是武汉版的"石库门"。
- 形制：**总里—支里**的鱼骨状布局；单元为**两层（或三层）联排住宅**，内有小天井；外墙**清水红砖或青砖**，门楣做**西式山花或中式砖雕**，配**石库门框、百叶窗、铁艺阳台**。
- 代表里分：**江汉村、洞庭村、上海村、大陆坊、咸安坊、坤厚里、德兴里、三德里、平安里、联保里**等。
  - **咸安坊**（1915 年）是汉口保存最完整的里分之一，曾为高级职员住宅；
  - **江汉村**（1930 年代）为"**公寓式**"里分，设施较现代。
- 里分是**近代汉口城市化**的载体：商号职员、银行雇员、小手工业者混居，形成"**前街后里**"的商住格局。

## 四、汉口租界与江汉关

- **1861 年**汉口开埠，英、俄、法、德、日等国先后在汉口设**租界**，沿江大道一线形成**万国建筑群**。
- **江汉关大楼**（1924 年建成）是汉口的标志性建筑，英国古典主义风格，钟楼仿英国国会大厦大本钟，报时钟声曾是全城的作息信号；现为**江汉关博物馆**。
- 沿江其他建筑：**汇丰银行、花旗银行、麦加利银行、德华银行、俄国领事馆、法国领事馆、美国领事馆**旧址等。
- **黎黄陂路**一带（原俄租界）保留较完整的街头博物馆式建筑群，被称为"**街头博物馆**"。

## 五、非遗与市井

- **汉剧**（旧称"楚调"）是中国最古老的剧种之一，对**京剧**的形成有直接影响（"**徽汉合流**"），2006 年列入国家级非物质文化遗产。
- **楚剧**、**湖北大鼓**、**武汉木雕船模**、**汉绣**亦为国家级非遗。
- **过早**是武汉人最重要的日常仪式——"**过早**"（吃早餐）一词为武汉独有，**热干面、豆皮（三鲜豆皮）、面窝、糊汤粉**是代表；**户部巷**与**吉庆街**是最著名的过早与夜市街区。

## 六、漫步建议

- 半日路线（武昌）：昙华林 → 瑞典教区旧址 → 崇真堂 → 文华书院旧址 → 花园山 → 户部巷（过早）→ 黄鹤楼 → 长江大桥步道。
- 半日路线（汉口）：江汉关 → 沿江大道万国建筑群 → 黎黄陂路 → 咸安坊 → 江汉村 → 吉庆街（夜市）。
- 观察题：里分门楣的中西合璧装饰；总里与支里的层级；清水红砖的砌法（英式"一顺一丁"）；江汉关钟楼的三段式立面；昙华林山坡上的高差处理。

## 七、人文短句

- "过早"两个字，是武汉人给早餐最高的礼遇。
- 一条 1200 米的街上，教堂、佛寺、学堂、医院挤在一起——这是武昌的包容。
- 里分的门口写着"某某里"，进去是一条街，出来是一个时代。
