# 通识 · 中国古代都城营建：从里坊到街巷

> 类型：古建筑通识　适用：理解一座老城为什么长这样
> 一句话：唐以前是"**封闭的棋盘**"（里坊制），宋以后是"**开放的街市**"（街巷制）——中国城市史最关键的一次转身。

## 一、《考工记》：中国都城的理想蓝图

- **《周礼·考工记》**记载的营国制度："**匠人营国，方九里，旁三门。国中九经九纬，经涂九轨。左祖右社，面朝后市，市朝一夫。**"
- 关键词解读：
  - **方九里、旁三门**：都城为方形，每边开三座城门（共 12 门）；
  - **九经九纬**：南北、东西各九条主干道；
  - **左祖右社**：宫殿左侧（东）为**太庙**（祭祖），右侧（西）为**社稷坛**（祭土地与谷物）；
  - **面朝后市**：前（南）为朝堂，后（北）为市场；
  - **中轴对称**：全城以一条南北中轴线组织。
- 这一理想在后世不断被追摹：**曹魏邺城、北魏洛阳、隋大兴/唐长安、元大都、明清北京**一脉相承。**北京中轴线**（2024 年列入《世界遗产名录》）是其最完整的实现。

## 二、里坊制：唐长安的封闭棋盘

- **里坊制**（又称"**坊市制**"）成熟于**北魏洛阳**，鼎盛于**隋大兴—唐长安城**。
- 做法：城内用**棋盘格道路**分割成若干封闭的**"坊"**（居住区）与**"市"**（商业区，长安为**东市、西市**）。
  - 坊四周有**坊墙**，四面或两面开**坊门**，由**坊正**管理；
  - **宵禁**：日暮击鼓闭门，五更开坊门（"**晨鼓暮钟**"）；
  - **商业只能在"市"内进行**，市也有固定营业时间。
- **唐长安**由**宇文恺**规划，面积约 **84 平方公里**，设 **108 坊**（一说 110 坊）+ 东西两市，人口逾百万，是当时**世界上最大的城市**。
- 优点：**便于管理、治安好**；缺点：**商业受限、生活不便**。
- 遗存对照：今**西安**的城墙即唐**皇城**范围；**日本平城京（奈良）、平安京（京都）**仿唐长安建制，是里坊制在海外的最完整样本。

## 三、街巷制：宋代的"商业革命"

- 唐末至**北宋**，坊墙被推倒，商业突破"市"的限制——**沿街开店、临街设铺**成为常态，形成"**街巷制**"。
- 标志：《**清明上河图**》（北宋张择端）所绘的开封，正是**店铺临街、招牌林立、夜市通宵**的街巷制城市。
- **北宋东京（开封）**打破宵禁，出现**夜市**与**晓市**；**南宋临安（杭州）**的**御街**两侧亦店铺密布。
- 结果：城市从"**管理型**"转为"**生活型**"，**街巷的名称、宽度与商业业态**成为城市记忆的载体（今日老街的"**前店后宅、下店上宅**"即源于此）。

## 四、中轴线与"择中"的思想

- **"择中"**："**王者必居天下之中**"（《荀子》），都城选址追求地理中心（洛阳"**天下之中**"）与礼制中心（轴线）。
- 中轴线是**礼制秩序的空间化**：宫城居中、左祖右社、前朝后寝，轴线越长、层次越多，等级越高。
- 实例：**曹魏邺城**（中国最早的中轴对称都城规划之一）、**隋大兴/唐长安**（朱雀大街宽约 150 米）、**元大都**（中轴线 7.8 公里）、**明清北京**。

## 五、城墙体系：一座城的防御语法

| 构件 | 作用 |
|---|---|
| **城墙** | 主体防御，外包砖、内夯土 |
| **马面（敌台）** | 突出墙外的墩台，间距约 120 米（恰为弓箭有效射程），消除防守死角 |
| **垛口（雉堞）** | 墙顶齿状矮墙，遮挡射击 |
| **敌楼** | 马面上的建筑，屯兵瞭望 |
| **瓮城** | 城门外的封闭小城，诱敌深入后四面合围（"**瓮中捉鳖**"） |
| **箭楼 / 闸楼** | 瓮城上的防御楼，箭楼射击、闸楼控吊桥 |
| **护城河 + 吊桥** | 外围水系与可升降的通路 |
| **角楼** | 城墙转角处的楼，视野最佳 |
| **藏兵洞** | 城墙内部或瓮城内的屯兵空间（南京中华门有 27 个） |

- **城砖责任制**：南京明城墙的城砖刻有**提调官、司吏、窑匠、人夫**姓名，是最早的**质量追溯制度**（"**物勒工名**"传统的极致）。

## 六、水系：城市的血管

- **江南水乡**（苏、绍、周庄）：**水陆并行、河街相邻**的"**双棋盘**"格局（苏州平江路是典范）——河是运输通道，街是人行商街，**河埠头**是水陆的接口。
- **运河城市**（扬州、杭州、济宁）：城市沿运河展开，**码头、钞关、会馆**构成商业轴线。
- **山地城市**（重庆、丽江）：水系决定道路与聚落形态，**丽江三河穿城**并约定"上游饮用、中游洗菜、下游洗衣"。
- **缺水的西北**：**坎儿井**（新疆）是地下引水系统，通过竖井与暗渠把雪山融水引到绿洲。

## 七、Citywalk 怎么读一座城

1. **先看城墙/护城河的轮廓**——城有多大多规整，反映的是建城时的等级与规划思想。
2. **找中轴线**——政府机构、庙宇、钟鼓楼往往在中轴上。
3. **看街道宽度与走向**——里坊制遗存是规整大格网；街巷制是自然生长、宽窄不一。
4. **看与水的关系**——沿河展开还是围井而建。
5. **看巷名**——"**米市、羊市、盐仓、兵马司**"是产业记忆，"**某某胡同/巷/坊/里**"是制度记忆。
6. **看门与墙**——垂花门、影壁、马头墙、封火墙，是礼制与防火的共同产物。
7. **看地面**——青石板（官修）、弹石（就地）、麻石（岭南）、面包石（近代租界）。
