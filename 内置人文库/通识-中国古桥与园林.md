# 通识 · 中国古桥与园林

> 类型：古建筑通识　适用：读懂水乡的桥与江南的园
> 一句话：桥是水乡的路与广场，园林是把山水搬进院子——两者都是中国人处理"人与自然"的答案。

## 一、中国古桥的四种基本类型

### 1. 梁桥（平桥、石板桥）
- 最简单古老的形式：**桥墩 + 石梁**。
- **石梁桥**代表：**泉州洛阳桥**（北宋**1053—1059 年**建，中国现存最早的**跨海梁式大石桥**，首创"**筏形基础**"（抛石成堤）与"**种蛎固基**"（养牡蛎胶固基石），长 731 米）。
- **伸臂梁桥**（木伸臂）：层层挑出木梁缩短跨度，适应深谷（如甘肃**灞陵桥**、广西**程阳风雨桥**的底层结构）。
- **廊桥（风雨桥）**：在梁桥上加**桥屋、桥廊、桥亭**，供人避雨休憩、会客交易。**浙江泰顺廊桥**、**广西侗族程阳永济桥**、**福建寿宁鸾峰桥**为代表作。**木拱廊桥（编木拱梁桥）**以木构件交叉编织成拱，不用一根钉铆，是"**中国木拱桥传统营造技艺**"，2009 年列入 UNESCO **急需保护的非物质文化遗产名录**。

### 2. 拱桥（券桥）
- **敞肩圆弧石拱桥**是中国对世界桥梁史的最大贡献——**赵州桥（安济桥）**：
  - 隋**大业年间（605—616 年）**由**李春**设计建造，位于河北赵县洨河上；
  - **净跨 37.02 米**，是世界上现存**最古老的敞肩圆弧石拱桥**；
  - "**敞肩**"指在主拱两肩各开两个小拱——既**减轻自重**（约减重 700 吨）、**增大泄洪量**，又**美观**；这一技术比欧洲早约 **1200 年**。
- **厚墩联拱**：**卢沟桥**（金**1189—1192 年**，11 孔联拱，以**485 个石狮**闻名）。
- **薄墩薄拱（驼峰式）**：江南水乡常见，拱薄墩轻、桥身隆起如驼峰，与平缓的河道相适应（如**苏州**的众多石拱桥）。
- **多孔连续拱**：**北京卢沟桥、颐和园十七孔桥**。

### 3. 索桥（悬索、铁索、藤索）
- 西南山区与峡谷地带：**泸定桥**（清**1706 年**，13 根铁链，跨大渡河）、**都江堰安澜索桥**（竹索）、**西藏、云南的溜索**。
- 特点是**跨度大、材料省**，但行走晃动，是山地交通的智慧。

### 4. 浮桥与特殊形式
- **浮桥**：以船或筏串联成桥（**蒲津渡浮桥**唐代以铁牛为锚，山西永济出土唐代**黄河铁牛**）。
- **八字桥**（绍兴，南宋）：三向四路汇于一桥，被视为**中国古代立交桥**的雏形。

## 二、水乡的桥：不只是交通

- **功能复合**：**交通 + 集市 + 社交 + 风水**。江南"**桥头市**"就是因桥形成的商业点；桥头常设**桥亭、土地祠、凉亭、埠头**。
- **桥与门的对应**：水乡人家"**出门见桥、下桥进船**"，桥的踏步（**踏道**）与河埠头（**河埠**）是水陆接口。
- **桥名的文化**：**思婆桥、乌鹊桥、宝带桥、枫桥**（"**江枫渔火对愁眠**"）——桥名往往就是地名与诗。
- **苏州**曾有"**三步两桥**"之说；**绍兴**曾为"**万桥之乡**"，城内曾有桥 229 座（历史统计）。
- **宝带桥**（苏州，唐**816 年**始建，53 孔连拱，长 316.8 米，是中国现存最长的多孔石拱桥之一）。

## 三、中国园林：把山水搬进院子

### 分类
| 类型 | 代表 | 特征 |
|---|---|---|
| **皇家园林** | 颐和园、承德避暑山庄、圆明园（遗址） | 规模宏大、真山真水、建筑华丽、兼具理政与游憩 |
| **私家园林（文人园）** | 苏州拙政园、留园、网师园；扬州个园；无锡寄畅园 | 小中见大、以水为中心、诗画意境、叠山理水 |
| **寺观园林** | 各大寺庙庭院 | 宗教性与公共性 |
| **公共园林（湖山）** | 杭州西湖、扬州瘦西湖 | 城市与山水互相借景 |

### 造园四大要素
1. **叠山**：用**太湖石、黄石、宣石**堆叠假山。太湖石讲究"**瘦、皱、漏、透**"。扬州个园的**四季假山**是叠山的教科书。
2. **理水**：**聚则辽阔、散则曲折**；水面"**以小见大**"，靠**曲折岸线**与**桥、堤、岛**制造层次。
3. **建筑**：**厅、堂、楼、阁、榭、舫、亭、廊、桥**。廊的作用是"**引导与框景**"，亭的作用是"**停留与观景**"。
4. **植物**：讲究"**四季有景、寓意在先**"——竹（气节）、梅（傲骨）、荷（高洁）、玉兰（富贵）、石榴（多子）。

### 造景手法（最常被引用的一组）
- **借景**：把园外的山、塔、天色"借"进园中（**颐和园借玉泉山塔**、**拙政园借北寺塔**）。
- **框景**：用门窗洞、廊柱形成的"框"去截取景色，如一幅画（**网师园殿春簃**的窗）。
- **对景、隔景、障景、漏景、夹景、添景**。
- **小中见大**：以**曲折、遮挡、层次**制造面积错觉——这是私家园林的核心技巧。
- **"壶中天地"**：文人把宇宙装进一方庭院，是"**不下堂筵，坐穷泉壑**"的理想。

### 世界遗产中的中国园林
- **苏州古典园林**：**1997 年**首批 4 座（拙政园、留园、网师园、环秀山庄）列入《世界遗产名录》，**2000 年**增补（沧浪亭、狮子林、艺圃、耦园、退思园），共 **9 座**。UNESCO 评价其"**咫尺之内再造乾坤**"。
- **颐和园**（1998）、**承德避暑山庄及周围寺庙**（1994）为皇家园林的世界遗产。

## 四、Citywalk 观察清单

**看桥**：
1. 桥是拱还是梁？（判断年代与地域）
2. 拱是半圆还是圆弧？（半圆多北方/唐以前，圆弧薄拱多江南）
3. 有没有"敞肩"小拱？（赵州桥体系）
4. 桥面有无桥屋？（廊桥/风雨桥）
5. 桥头有什么？（亭、庙、市、埠头）
6. 桥下的水位与桥洞的关系（泄洪与通航）

**看园**：
1. 水面占多少？岸线是否曲折？
2. 假山用什么石头？（太湖石 / 黄石 / 宣石）
3. 有没有借到园外的景？（站在亭子里往外看）
4. 廊在引导你往哪走？（"**步移景异**"）
5. 匾额楹联写了什么？（"**与谁同坐轩**""**听雨轩**"——园名即景题）
6. 地面的铺装图案（花街铺地，用卵石、碎瓦拼出图案）
