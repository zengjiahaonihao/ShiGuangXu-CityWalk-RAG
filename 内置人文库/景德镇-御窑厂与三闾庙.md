# 景德镇 · 御窑厂与三闾庙

> 城市：江西景德镇　资料类型：老街史料 / 手工业遗产
> 一句话：一座靠一门手艺活了一千年的城市——窑火不熄，瓷业不止。

## 一、千年窑火：从昌南镇到瓷都

- 景德镇古称"**昌南镇**"（昌江之南），**北宋景德元年（1004 年）**因镇产青白瓷（影青）受宋真宗赏识，遂以年号"景德"赐名，景德镇由此得名，沿用千年。
- 制瓷史可上溯至**汉代**（"新平冶陶，始于汉世"），**五代**已能烧造优质白瓷，**宋**创影青，**元**设**浮梁磁局**、创青花与釉里红，**明**设**御器厂**（后称御窑厂），**清**有督陶官（唐英），达到技艺顶峰。
- **China** 一词与"**昌南**（Changnan）"的关联，是中国陶瓷史中最常被引用的语源故事之一（此说流传广但学界尚有讨论）。
- 明清时期景德镇是**世界最大的制瓷中心**，有"**匠从八方来，器成天下走**"之说。

## 二、御窑厂：明清两代的皇家窑场

- **景德镇御窑厂**始建于**明洪武二年（1369 年）**，是明清两代专门为皇室烧造瓷器的官办窑厂，延续 **542 年**（至 1911 年）。
- 御窑厂的制度特点：**官搭民烧**（明代后期起，御器把部分烧造任务交给民窑），使最精的技艺在官窑与民窑之间流动。
- **御窑厂国家考古遗址公园**内保存有大量窑炉遗迹与**落选品掩埋坑**——御窑烧造"**百选一二**"，不合格者一律**打碎深埋**，不得流入民间，故遗址出土大量可复原的明代官窑瓷器碎片。
- 代表性器物：**永乐甜白、宣德青花、成化斗彩、康熙五彩、雍正粉彩、乾隆各色釉大瓶**。
- **唐英**（1682—1756），清代督陶官，在景德镇协理陶务 20 余年，著《**陶冶图编次**》《**陶成纪事碑**》，是中国陶瓷工艺史上最重要的文献之一。

## 三、三闾庙与里弄：瓷业城市的肌理

- **三闾庙**历史街区位于昌江西岸，是景德镇**现存最古老的街区之一**，明清时为**瓷器、窑柴的重要集散码头**。街区内有明清古街、古码头、古店铺遗存。
- **景德镇里弄**是特有的城市单元：由**坯房**（作坊）、**窑房**、**住宅**混合组成的片区。典型格局是"**前店后坊、上宅下厂**"。
- 老城区内的**中山北路、中华南路**一带还有大量**民国瓷行、钱庄**建筑——民国时期景德镇有"**日进斗金**"的瓷行街。
- **陶溪川**（原国营宇宙瓷厂）与**御窑博物馆**是近年的工业遗产改造项目，旧窑炉与厂房被改造为美术馆与文创街区。

## 四、制瓷七十二道工序

- 传统景德镇制瓷有"**过手七十二，方克成器**"之说，核心工序包括：
  - **采矿—粉碎—淘洗—制不（dǔn）**：瓷石、高岭土经水碓粉碎、淘洗沉淀成砖状"**不子**"；
  - **拉坯—利坯—施釉—画坯**；
  - **装匣—满窑—烧窑**（柴窑需持续投柴 20 余小时，窑温约 1300℃）；
  - **开窑—拣选—包装**。
- **高岭土**的发现与使用是景德镇瓷器的关键：瓷石 + 高岭土的"**二元配方**"提高了瓷胎的耐火度，使大件器物成为可能。"**Kaolin**"即由"高岭"音译而来。
- **景德镇手工制瓷技艺**2006 年列入**第一批国家级非物质文化遗产名录**。

## 五、漫步建议

- 半日路线：御窑厂国家考古遗址公园（看窑炉遗迹与掩埋坑）→ 御窑博物馆 → 抚州弄 → 中山北路老瓷行 → 三闾庙古街（昌江边看古码头）。
- 半日路线二：陶溪川文创街区（旧宇宙瓷厂）→ 景德镇中国陶瓷博物馆 → 三宝国际陶艺村。
- 观察题：匣钵与窑砖的重复使用痕迹；坯房的天井采光；古码头与河岸高差；老街上被独轮车磨出凹槽的青石板；里弄门楣上的窑户标记。

## 六、人文短句

- "匠从八方来，器成天下走。"
- 御窑的规矩是：不好的，就地打碎，埋进土里——六百年后挖出来，还是惊世骇俗。
- 一座城市的年号，是一千年前皇帝给它起的，因为它烧出了一只好碗。
